# Handoff: yAdventures-bosses

Personal-use datapack + resource pack for **Minecraft Java 26.3**. Git repo (`master`, remote `origin` on GitHub; don't push unless asked). Read `docs/`
first (`README.md`, `mechanics.md`, `content.md`, `scripts.md`, `minecraft-notes.md`).

## Ground rules
- Namespace is `yadventures-bosses`. The only `yadventures` things are the heart-pack hooks:
  `yadventures:compat/bosses_loaded` and the entity tags `yadventures.boss.{wildfire,iceologer,illusion}`.
  The pack used to be namespaced `yadventures`. That collided with the heart pack's
  `yadventures:load`, so the boss pack never loaded. Never put a load/tick function in `yadventures`.
- Sources: datapack.wiki and minecraft.wiki. When unsure of a 26.3 format, check the vanilla jar
  (below): 26.x loot uses `modifier`/`condition` keys, not `functions`/`conditions`.
- Only commit when asked. Use conventional commits (`feat(scope): ...`, `fix: ...`, `docs: ...`).
- Most of the pack is generated by Sandstone from `src/*.ts` (`npm run build`, output in
  `.sandstone/output/`, not committed). Hand-maintained files are in `resources/` (structures,
  worldgen, chest loot, textures, sounds) and `vendor/` (vanilla files); see `docs/scripts.md`.

## Recently done (all verified on a test server)
- **2026-09-28** (verified on the test server):
  - Iceologer milk flicker fixed: the milk is disguised in place as the body (`MILK_DISGUISE`).
  - Iceologer stray spell (state 3).
  - Signature drops (totems, crown fragments) moved from the bosses into both vaults.
  - Spawner lock: once per player per difficulty (`spawner/tick`), cooldown 1 min.
  - Trial spawners and vaults are pickaxe-mineable, slowed to ~15 s with diamond Efficiency V
    (`mining/tick`).
  - Boss health: base ×1.5, ominous ×1.5, easy ×0.5, hard ×1.5 (modifiers in `convert/run`).
  - Wildfire: one attack at a time, 3–5 s between attacks (ominous 2–3.5 s), `wildfire/next_attack`; charge
    attack when the target is 6–20 blocks away (`wildfire/charge/*`).
  - `commands/give/<boss>_trial_blocks` for placing them by hand.
  - Structure editing workflow: `docs/scripts.md`.
- Wildfire fixed: the model turns toward its target, the vanilla blaze fireballs are removed
  (its own volleys are tagged `debris`), and the shields work (`shield_hp` = max health × 25).
- Structures no longer spawn mobs continuously (`spawn_overrides` is `{}`).
- **Trial spawner system:** each lair's setup marker places a trial_spawner on the floor, plus
  normal and ominous vaults.
  - Spawned mobs are tagged `convert` and turned into bosses by `convert/run`, then leashed to
    within 32 blocks of home.
  - Killing a boss ejects a custom key. Each key only opens its own boss's vault of the same kind
    (normal or ominous).
  - Bad Omen switches the spawner to ominous, which spawns a buffed boss.
  - Summon helpers: `commands/summon/{,ominous_}<boss>`.
- **Rarity:**
  - Iceologer cabin: 56/14.
  - Illusioner shack and training grounds merged into one set (`illusioner_lairs`): 40/10.
  - Citadel: 32/10.
- **Explorer maps** (`loot_table/maps/<citadel|iceologer|illusioner>`, `give/<x>_map`):
  - Icons reuse the unused vanilla marker types, retextured (`target_x`, `target_point`,
    `blue_marker`). Each map has its own item texture.
  - Citadel map: in bastion treasure (50%) and other bastion chests (10%).
  - Illusioner map: in woodland mansion chests (10%). These come from overridden vanilla tables,
    vendored in `vendor/loot_table/`.
  - Iceologer map: a journeyman cartographer trade for snowy villagers only (13 emeralds +
    compass), added via the tag `#minecraft:cartographer/level_3`.

## Test tooling (in /tmp; it may be gone after a reboot)
- Server: `/tmp/yab-test/srv` (currently stopped, `server.properties` set to the flat `world`;
  `world2` = normal world, seed 12345, `allow-flight=true`).
  Start from the srv dir:
  `/tmp/yab-test/jdk-25.0.4.1+1/bin/java -Xmx3G -jar server.jar nogui > log.txt 2>&1 &`
- Deploy:
  `npm run build && rm -rf /tmp/yab-test/srv/<world>/datapacks/yadv && cp -r .sandstone/output/datapack /tmp/yab-test/srv/<world>/datapacks/yadv && python3 scripts/rcon.py reload`
- RCON: `python3 scripts/rcon.py "cmd" "cmd" ...` (from the project dir).
- Bot player "Tester": `/tmp/yab-test/restart_bot.sh [secs]`. Never `pkill -f bot.py` inline: it
  kills the tool's shell. The bot can also act on files it reads:
  - Use a block: write `x y z face` to `/tmp/yab-test/use.txt`.
  - Interact with an entity: write the entity's UUID as 32 hex chars to
    `/tmp/yab-test/interact.txt`. Summon the entity with a known `UUID:[I;a,b,c,d]` next to the bot.
- Vanilla data: `/tmp/yab-test/jd/data/minecraft`. Client assets: `/tmp/yab-test/cl`.
  Decompile with `jdk-25.0.4.1+1/bin/java -jar /tmp/yab-test/cfr.jar <class>`.
  Jars: `srv/versions/26.3/server-26.3.jar` and `/tmp/yab-test/client.jar`.
- Pillow for image work: `PYTHONPATH=/tmp/yab-test/pylib`. The map icons were made by
  `/tmp/yab-test/icons/make.py`.
